# Cursor rules — TabsUp

These rules apply to all AI-assisted work in this repository.

## Product & design

- **No redesign** of existing screens unless the task explicitly asks for visual or structural changes.
- **No feature invention**: implement only what is described in the task, issue, or linked plan. If something is ambiguous, ask or leave a short note—do not add “nice to have” behaviour.

## Git & tooling

- **No Git actions** (commit, push, branch, merge, rebase, etc.) **unless the user explicitly asks**.

## Execution style

- **Phased work only**: when a plan lists phases, complete or propose work in phase order; do not skip ahead without agreement.
- **Always summarise changes** at the end: what files changed, what each change does, and anything the user should verify manually.

## Scope

- Prefer **minimal diffs**. Do not modify app code, Xcode project files, or assets when the task is documentation-only (or vice versa—respect the stated scope).
